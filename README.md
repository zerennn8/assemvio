# Assemvio

Open index.html in any browser, or serve this folder with a static web server.

Responsive website with an illustrative connector check and optional browser voice playback. Factory demo requests open the visitor's email app addressed to olympicdang08@gmail.com. The visitor reviews and sends the email; the site does not store submissions.

Assemvio is a provisional brand. Google Fonts are optional; system fonts work offline. Product artwork is included as inline SVG.
